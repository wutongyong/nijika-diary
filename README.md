# 虹夏日记 🎸

一个以《孤独摇滚！》中的虹夏为主角的 AI 日记生成 Web 应用。虹夏会根据日期、季节、特殊纪念日以及你分享的心情，自动生成一篇符合她性格的日记，并支持语音朗读。

---

## 快速开始

### 环境要求

- Node.js (v16+)
- npm
- （可选）本地 TTS 语音服务，用于虹夏朗读功能

### 启动方式

**方式一：双击启动**

直接运行 `启动.bat`，浏览器打开 http://localhost:3000

**方式二：命令行启动**

```bash
npm install
node server.js
```

---

## 核心功能

### 🤖 AI 日记生成

- **每日自动生成** — 点击"让虹夏写下今天"，AI 会根据当前日期、季节、星期自动生成日记
- **互动日记** — 告诉虹夏你今天的心情、发生了什么、吃了什么，她会在日记中回应你
- **连续性记忆** — 虹夏会参考最近 3 天的日记内容和读者回复，保持故事连贯
- **纪念日彩蛋** — 2月21日（虹夏生日）、3月13日（乐队成立日）、7月27日（乐队周年纪念）等特殊日期，日记中会自然提到

### 💌 读者互动

- **回复日记** — 给虹夏写回复，她会在下一篇日记中回应你
- **回复统计** — 侧边栏实时显示总回复数和互动日记数

### 🔊 虹夏朗读（TTS）

- 中文日记 → 自动翻译为日语 → 虹夏语音合成朗读
- 支持暂停/继续播放

### 🔍 日记搜索

- 全文搜索日记标题、内容和回复
- 支持回车快捷搜索，一键清除搜索结果

### 🎲 随机阅读

- 点击"随机阅读"按钮，随机打开一篇日记

### 📄 导出日记

- 日记详情页支持导出为 .txt 文本文件

### 🗑️ 删除日记

- 日记详情页支持删除，带二次确认弹窗

### ⚙️ API 配置

通过侧边栏底部的「API 配置设置」按钮或直接编辑 `config.json`：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| API 密钥 | MiMo AI 模型的 API Key | - |
| API 地址 | AI 模型的接口地址 | `https://token-plan-cn.xiaomimimo.com/v1` |
| 模型名称 | 使用的 AI 模型 | `mimo-v2.5-pro` |
| TTS 端口 | 本地 TTS 语音服务端口 | `5000` |

### 📊 数据统计

侧边栏显示：

- 日记总数
- 回复总数
- 互动日记数
- 连续写日记天数
- 总字数
- 首篇日记日期

### 🗓️ 日历导航

- 侧边栏日历直观展示有日记的日期（粉色圆点标记）
- 点击任意日期翻阅或自动生成该日日记
- 支持月份切换，快速跳回当月

### ⌨️ 快捷键

| 按键 | 功能 |
|---|---|
| Esc | 关闭弹窗 / 返回日记列表 |
| Enter | 提交心情 / 发送回复 |

- 滚动超过 300px 后页面右下角出现"回到顶部"按钮

## 项目结构

```
├── 启动.bat          # Windows 一键启动脚本
├── server.js         # Node.js 服务端（Express）
├── config.json       # API 配置文件（可自定义）
├── package.json      # npm 项目配置
├── api_spec.json     # TTS 服务 API 规范
├── data/             # 日记数据存储（按日期）
│   ├── 2026-05-03.json
│   └── ...
└── public/
    └── index.html    # 前端单页应用
```

## API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/diaries` | 获取所有日记列表 |
| GET | `/api/diaries/:date` | 获取指定日期日记 |
| POST | `/api/diaries/generate` | 指定日期生成日记（支持心情参数） |
| POST | `/api/diaries/auto-generate` | 自动生成今日日记 |
| DELETE | `/api/diaries/:date` | 删除指定日期日记 |
| GET | `/api/diaries/search?q=` | 搜索日记 |
| GET | `/api/diaries/random` | 随机获取一篇日记 |
| POST | `/api/diaries/:date/reply` | 给日记添加回复 |
| GET | `/api/dates-with-diaries` | 获取所有有日记的日期 |
| GET | `/api/stats` | 获取统计数据 |
| GET | `/api/config` | 获取当前配置 |
| POST | `/api/config` | 更新配置 |
| POST | `/api/tts` | 生成语音（中→日翻译→朗读） |
